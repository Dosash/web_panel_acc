# История изменений

## 0.10.0 — 2026-10-23
Программа для Windows, Linux и macOS (`desktop/`) и единые обновления.
- **Подключение к своему серверу**: при первом запуске программа спрашивает, где работают аккаунты. «На моём
  сервере» — программа открывает вашу веб-панель (например, `http://192.168.3.18/accounts/`): аккаунты, папки
  и любые правки панели одни и те же на всех устройствах, обновлять программу ради них не нужно. Если сервер
  недоступен — свой экран и переподключение каждые 10 секунд. Сменить — трей → «Подключение…»
- **Автообновление программы**: раз в 6 часов программа проверяет GitHub Releases, сама скачивает версию
  под свою систему и после перезапуска ставит её (установщик Windows — тихо, portable, AppImage, tar.gz, macOS).
  Если окно свёрнуто в трей — обновляется сразу; иначе спрашивает «Перезапустить сейчас / При выходе».
  В трее — «Проверить обновления» и «Обновлять автоматически»
- **Релиз без ручных шагов**: повысили `VERSION` в `app/config.py` и влили в main — GitHub Actions собирает
  программу под все системы и публикует релиз `vВЕРСИЯ` с описанием из этого файла
- Та же панель отдельной программой, без сервера и браузера: внутри сервер из `app/` и интерфейс из `static/`
  в окне Qt WebEngine, поэтому функции совпадают с веб-панелью
- Вход без пароля (сервер только на `127.0.0.1`, cookie ставит сама программа), кнопка «Выйти из панели» скрыта
- Трей: закрытие окна сворачивает программу, аккаунты остаются на связи; меню — открыть, папка с данными,
  запуск при входе в систему, выход. Системные уведомления, когда окно свёрнуто или не в фокусе
- Файлы сохраняются через «Сохранить как», фото и видео открываются в отдельном окне, внешние ссылки —
  в системном браузере; разрешения камеры, микрофона и геопозиции для мини-приложений — по запросу
- Одна запущенная копия, запоминание окна, масштаба и порта; журнал в папке данных
- Сборка: `desktop/build.py` (PyInstaller) — AppImage и tar.gz с `install.sh` для Linux, установщик Inno Setup
  и переносной zip для Windows, dmg для macOS (Apple Silicon и Intel); под все системы — GitHub Actions
  (`.github/workflows/desktop.yml`)

## 0.8.0 — 2026-10-23
Мини-приложения ботов и ссылки t.me внутри панели.
- Мини-приложения (Web App) открываются прямо в панели: кнопка-приложение под сообщением бота,
  кнопка меню бота слева в поле ввода, ссылки `t.me/бот/приложение` и `t.me/бот?startapp`.
  Работают главная и дополнительная кнопки, «Назад», тема панели, всплывающие окна, полноэкранный режим;
  приложение можно перезагрузить или открыть в новой вкладке. Оплата, номер телефона и QR-сканер
  из панели не передаются — приложение получает отказ
- Ссылки на каналы, группы, ботов и приглашения (`t.me/…`, `tg://…`) открываются в панели, а не в новой
  вкладке: карточка с описанием и числом подписчиков, «Посмотреть» без подписки и «Подписаться»;
  у ботов — «Запустить» с параметром из ссылки. Ссылка на пост открывает канал на этом посте.
  Ctrl+клик по-прежнему открывает ссылку в новой вкладке
- Канал, открытый без подписки, можно читать; внизу кнопка «Подписаться»
- Каналы с коллекционными @именами (Fragment) показывают своё имя
- `POST /api/accounts/{aid}/join` принимает `chat_id` — подписка на найденный по ссылке канал

- Исправлено: «Приглашение» и «Копировать» падали с ошибкой `writeText`, когда панель открыта по http

- Подсказка аккаунта больше не перекрывает контекстное меню

## 0.6.0 — 2026-10-23
Запуск на сервере через Docker и работа рядом с другими панелями.
- Запуск одной командой: `docker compose up -d --build` (`Dockerfile`, `docker-compose.yml`, проверка
  здоровья контейнера); без Docker — `./run.sh` или `python -m app`
- Панель может работать не в корне сайта: `WEB_PREFIX=/accounts` → `http://сервер/accounts/`
  (за общим nginx рядом с другими панелями). Все адреса интерфейса стали относительными
- Ссылка «Все панели» в левой колонке (`HUB_URL`)
- `GET /api/health` без пароля: статус, версия, число аккаунтов в сети и с ошибкой
- `GET /api/session` возвращает также `version` и `hub_url`
- Настройки переименованы как в других проектах: `WEB_HOST`, `WEB_PORT`, `WEB_PASSWORD`
  (старые `HOST`, `PORT`, `PANEL_PASSWORD` тоже работают)
- Cookie входа ставится только на путь панели — не мешает соседним панелям на том же сайте
- Лицензия MIT; новая документация: установка на сервер по шагам, доступ к панели, бэкап и перенос, частые проблемы

## 0.5.0 — 2026-10-23
Меню чата и папки.
- Правый клик (на телефоне — долгое нажатие) по чату открывает меню: «Прочитать всё», «О канале»,
  «Закрепить / Открепить», «Выключить / Включить уведомления», «Добавить в папку», «Архивировать»
- Закрепление чатов работает через Telegram; закреплённые чаты наверху и в режиме «Все аккаунты»
- Уведомления выключаются в Telegram; браузер тоже не уведомляет о чатах без звука
- Папки панели: создание, переименование и удаление (правый клик по вкладке), один чат может быть
  в нескольких папках, в одной папке — чаты разных аккаунтов
- Вкладки «Все чаты», «Непрочитанные», папки, «Архив» прокручиваются по горизонтали; у папок счётчик чатов
- Карточку «О канале» можно открыть из меню, не открывая сам чат
- Понятные русские тексты для частых ошибок Telegram (лимит закреплённых, занятая ссылка и др.)
- Исправлено: чат с истёкшим «без звука» больше не считается заглушённым

## 0.4.0 — 2026-10-23
Посты в каналах выглядят как в Telegram.
- Кнопки под постами: ссылки открываются в новой вкладке, кнопки ботов (callback, игры) нажимаются

- Ссылки из сообщений проходят проверку: открываются только http(s), tg:, mailto:, tel:
