# Демо-ролик TG Panel — исходники

Ролик `../demo.mp4` (1920×1080, 60 fps, H.264 + AAC, 44 с) и его превью для README `../demo.webp`
(800 px, 15 fps, без звука) целиком собраны из HTML/CSS/JS: это не запись экрана,
а детерминированная сцена, которую `render.py` отрисовывает покадрово через Chromium и склеивает через ffmpeg.
Интерфейс в кадре — настоящий `static/app.css` панели и её иконки (копируются при каждом рендере), данные выдуманы.

| Файл | Что |
|---|---|
| `demo.html` | сцена: 3D-мир (`#world`) с панелью, интро и телефоном, экранный слой (`#hud`) с подписями и финалом |
| `demo.css` | сцена, интро «пять окон», подписи, телефон, панель бота, финал; все анимации `app.css` выключены |
| `demo.js` | данные, сборка DOM панели, таймлайн `TL`, камера (монотонный сплайн), курсор, `renderAt(t)` |
| `audio.js` | музыка (100 BPM, пэд + арпеджио + бас + ударные + мелодия) и звуковой дизайн по тем же меткам `TL`; офлайн-рендер в WAV |
| `render.py` | кадры `i / 60` → ffmpeg; `--times` для стоп-кадров, `--step` для черновика, `--audio-only` |
| `fonts/` | Inter (Google Fonts) — локально, чтобы рендер не зависел от сети |

```bash
uv run --with playwright python docs/video/src/render.py --out docs/video/demo.mp4
ffmpeg -i docs/video/demo.mp4 -vf "fps=15,scale=800:-1:flags=lanczos" -c:v libwebp_anim -loop 0 -quality 60 -an docs/video/demo.webp
```

## Идея и раскадровка

Нить: **пять окон Telegram сворачиваются в одну панель, и всё дальнейшее происходит в ней** — камера ни разу не
покидает интерфейс до финала, каждая сцена вызвана действием курсора в предыдущей.

| Сцена, время | Что происходит | Выбранный вариант (из рассмотренных) |
|---|---|---|
| Интро, 0–4,8 | пять «окон» Telegram с аккаунтами плывут в глубине (DOF по дальности), заголовок «5 аккаунтов. 5 окон.» → «Одно окно.», окна слетаются в рейку аккаунтов | окна слетаются в рейку (вместо: телефон → монитор; падение папки tdata; только текст) — даёт глубину и причинно порождает панель |
| Панель, 4,8–12 | из рейки раскрываются список и чат (2.5D: слои разнесены по глубине и сходятся), каскад диалогов с цветными метками, клик по аккаунту «Продажи» — остаются его чаты | раскрытие из рейки + выбор аккаунта (вместо: вкладка «Непрочитанные»; поиск; папка) — показывает главное: один список и метки |
| Сообщение, 12–19,2 | приходит сообщение: диалог всплывает наверх, бейдж; клик — чат; наезд на поле ввода, набор ответа, отправка с пружиной | набор и отправка (вместо: ответ на сообщение; закрепление; правка) — самое понятное действие |
| Канал, 19,2–26,4 | «Все аккаунты» → канал с постами и кнопками, наезд на кнопки, «Приложение» открывает мини-приложение бота с загрузкой и карточками | мини-приложение (вместо: карточка канала по ссылке; управление админами) — самая заметная возможность |
| Боты, 26,4–31,2 | клик по иконке бота постинга: панель бота въезжает, карточки-показатели подпрыгивают, числа считаются, контент-план | обзор бота постинга (вместо: подключение по токену; бот рекламы) — богаче визуально |
| Темы и телефон, 31,2–36 | подъём звука, клик по теме — светлая тема раскрывается кругом от кнопки; камера отъезжает, справа влетает телефон с тем же чатом | круговое раскрытие + телефон (вместо: простое перетекание; две панели рядом) |
| Финал, 36–44,4 | панель уходит в глубину и из фокуса, логотип вылетает из рейки, «TG Panel» собирается по буквам, `docker compose up -d` печатается, ссылка на GitHub, удар на финальном аккорде | — |

Синхронизация: границы сцен лежат на тактах (такт 2,4 с), удар — на раскрытии панели (4,8), ударные уходят
в сцене смены темы (31,2–33,6) и возвращаются с телефоном, финальный аккорд — 43,2. Клики, набор текста,
всплытие карточек и свист переходов идут из тех же меток `DEMO.TL`, что и картинка.
