- [x] Переписка: текст, файлы, ответ, правка, удаление, закрепление; медиа
- [x] События в реальном времени через WebSocket; уведомления браузера

- [x] Каналы и группы: создание, вступление, редактирование, приглашения, выход
- [x] Профиль аккаунта и активные сеансы
- [x] Ленивые аватары с кэшем
- [x] Современный интерфейс: тёмная/светлая тема, иконки, группировка сообщений, телефон
- [x] Кнопки под постами, форматирование текста и скрытые ссылки, спойлеры, превью ссылок
- [x] Меню чата по правому клику: прочитать, о канале, закрепить, уведомления, папки, архив
- [x] Папки панели с чатами разных аккаунтов
- [x] Запуск в Docker, работа под своим путём рядом с другими панелями (`WEB_PREFIX`), `/api/health`

- [x] Мини-приложения ботов в панели; ссылки t.me открываются в панели с предпросмотром и подпиской
- [x] Окно «Поддержка» (значок $), скриншоты интерфейса в README на демо-данных
- [x] Программа для Windows, Linux и macOS (`desktop/`): окно Qt WebEngine, трей, уведомления, автозапуск, сборка в GitHub Actions
- [x] Программа: режим «на моём сервере», автообновление из GitHub Releases, релиз по новой версии в main
- [x] Цветные кнопки под постами; редактор оформленного поста для админов: форматирование, медиа, цветные кнопки через бота канала, подсказки
- [x] Значок «Вышло обновление» в панели и программе: обновить программу, панель на сервере или скачать с GitHub
- [x] Встроенные бот постинга и бот рекламы (`bots/`): запуск по токену из панели, их панели — внутри TG Panel

## Идеи с осторожностью

Массовые рассылки, автоинвайты и одинаковые действия со многих аккаунтов — частая причина банов.
Если делать, то с лимитами, случайными паузами и предупреждениями в интерфейсе.
