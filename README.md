# TG Panel

Веб-панель для управления несколькими Telegram-аккаунтами из одного окна.
Загружаете папку `tdata` от Telegram Desktop, даёте аккаунту имя — и работаете с ним из браузера:
переписка, каналы, группы, профиль, сеансы. Диалоги всех аккаунтов собраны в один список с цветными метками.

- Python 3.12 · FastAPI · Telethon · opentele
- Интерфейс без сборки: HTML + CSS + JS
- Данные хранятся локально в SQLite, сессии зашифрованы

## Быстрый старт

```bash
./run.sh
```

Первый запуск создаст окружение `.venv` (Python 3.12 через `uv`) и файл `.env`.
Панель откроется на **http://127.0.0.1:8080**.

## Как добавить аккаунт

1. Нажмите **+** в левой колонке.
2. Введите имя — так аккаунт будет подписан в панели.
3. Выберите **папку tdata** или **zip-архив** с ней. Кэш (`user_data`, `emoji` и т.п.) отсекается
   автоматически — загружаются только ключевые файлы.
4. **Отдельный сеанс** (включён по умолчанию, рекомендуется): панель войдёт как новое устройство,
   а tdata продолжит работать независимо. Если на аккаунте включена 2FA — укажите облачный пароль.
   Без галочки панель использует тот же ключ авторизации, что и tdata.
5. Если в Telegram Desktop стоит **локальный код-пароль** — укажите его.
6. **Прокси** (необязательно): `socks5://user:pass@host:port`, свой для каждого аккаунта.

Повторная загрузка tdata того же аккаунта обновляет его сессию, а не создаёт дубль.

## Возможности

| Раздел | Что умеет |
|---|---|
| Диалоги | Общий список всех аккаунтов или одного; вкладки «Чаты», «Непрочитанные», «Архив»; поиск |
| Переписка | Текст, файлы, ответ, редактирование, удаление, закрепление; медиа и превью ссылок |
| Реальное время | Новые сообщения, правки и удаления приходят сразу (WebSocket); уведомления браузера |
| Невидимка | Чтение без отметки «прочитано» (иконка глаза в левой колонке) |
| Каналы и группы | Создание, вступление по ссылке, название/описание/фото/публичная ссылка, приглашения, выход |
| Профиль | Имя, фамилия, @username, «о себе», аватар |
| Безопасность | Список активных сеансов аккаунта, завершение чужих |
| Интерфейс | Тёмная и светлая темы, работает с телефона |

Меню аккаунта — кнопка **⋯** над списком чатов (когда выбран аккаунт) или правый клик по аватару слева.

## Пароль панели

По умолчанию вход без пароля. Чтобы включить, впишите в `.env`:

```
PANEL_PASSWORD=ваш-пароль
```

и перезапустите `./run.sh`. **Без пароля не открывайте панель наружу** — `HOST` должен оставаться `127.0.0.1`.

## Веб-панель из локальной сети

Первой кнопкой в рейке можно открыть любую веб-панель из локальной сети (роутер, NAS, панели ботов).
Впишите в `.env`:

```
LAN_PANEL_URL=http://192.168.3.18/
LAN_PANEL_NAME=Панели ботов
LAN_PANEL_PROXY_PORT=8081
```

Сайты обычно запрещают встраивание, поэтому панель открывается через прокси TG Panel на порту
`LAN_PANEL_PROXY_PORT`. Если TG Panel открыта по https или порт прокси занят, кнопка откроет сайт
в новой вкладке (`LAN_PANEL_PROXY_PORT=0` — всегда так). Порт прокси должен быть доступен из браузера
так же, как основной; если нет — в шапке встроенной панели есть «Открыть в новой вкладке».

## Данные

| Путь | Что это |
|---|---|
| `data/panel.db` | Аккаунты; строки сессий зашифрованы |
| `data/secret.key` | Ключ шифрования сессий. Без него сессии не расшифровать — не теряйте и не передавайте |
| `data/cookie.key` | Ключ подписи cookie входа |
| `data/cache/` | Аватары и медиа; можно удалять |

Загруженная tdata **не сохраняется**: из неё берётся сессия, временная папка сразу удаляется.

## Важно

Telegram банит аккаунты за спам и массовые действия (рассылки, массовые вступления и инвайты).
Для нескольких аккаунтов давайте каждому свой прокси и не делайте одинаковые действия со всех сразу.
